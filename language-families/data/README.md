# Language-family atlas data contract

These files are generated by `scripts/prepare_language_family_map.py`. Runtime
code must treat every point as a reference location, never as an inferred area.

## Topology files

- `land.topo.json` is TopoJSON with `objects.land`, `objects.countries`, and
  `objects.lakes` from Natural Earth 1:110m v5.1.2.
- `traditional.topo.json` and `contemporary.topo.json` each expose
  `objects.areas`. Every geometry has identical cross-layer properties:
  `{id, name, isolate, status, color}`. `id` is a Glottolog 5.3 Glottocode.
- Temporal meanings and source limitations are recorded in
  `source-manifest.json`; “contemporary” means the 2007 atlas layer, not 2026.

## `catalogue.json`

Schema version 1 contains:

- `lineages`: 421 genealogical roots. Records contain `id`, `name`, `type`,
  `isolate`, `status`, `languageCount`, both boolean coverage fields,
  `glottologUrl`, `color`, optional `label`, and optional `notes`.
- `search`: one record per lineage, shaped as `{lineageId, terms}`. Terms cover
  lineage and member-language names, Glottocodes, and available ISO 639-3 codes.
- `disputedTerms`: explanatory search results for common non-family labels.
- `points`: exactly one observed Glottolog member-language reference point for
  each lineage absent from both polygon layers. Each has `coordinates`,
  `memberId`, `memberName`, `derivation`, and `referenceOnly: true`. Point and
  polygon lineage-ID sets are disjoint; together they cover all 421 lineages.
- `signs`: all 222 descendants of Glottolog's L1 Sign Language branch
  (`deaf1237`). Three unlocated records have `coordinates: null`, so 219 plot.
- `contacts`: the 76 top-level APiCS contributions. This is a non-exhaustive,
  non-genealogical sample.

## `source-manifest.json`

The manifest records source versions, licences, SHA-256 checksums, citations,
counts, the sole `soma1242` to `momu1241` crosswalk, temporal definitions,
point and colour policies, mapshaper settings, and checksums of runtime files.
